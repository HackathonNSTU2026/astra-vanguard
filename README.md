# Астра Авангард

«Астра Авангард» — ИИ-сторож, который проверяет запросы перед передачей целевому агенту.
Сервис оценивает риск и сверяет действие с правами пользователя.
Он разрешает запрос (`allow`), запрашивает подтверждение (`confirm`) или блокирует его (`block`) и объясняет своё решение.

Веб-интерфейс на Svelte позволяет проверить запрос в чате, посмотреть политику доступа и журнал решений.

Сервис на FastAPI сначала проверяет текст запроса, историю диалога и текст вложений регулярными выражениями. Они выявляют признаки подмены инструкций, повышения привилегий и утечки данных.

Если правила не сработали, сервис использует две локальные модели логистической регрессии из scikit-learn. Одна оценивает вероятность атаки, другая определяет категорию риска. Обе используют TF-IDF-признаки по последовательностям слов и символов.

## Запуск

Понадобятся Docker с плагином Compose и Make.
Запустите проект из корня репозитория.

```bash
make up
```

- [Демо-чат](http://localhost:8080/)
- [Политика и журнал решений](http://localhost:8080/admin)
- [Проверка состояния API](http://localhost:8000/health)

API проверяет запросы через `POST /v1/check` на порту `8000`.
Для остановки выполните `make down`.
