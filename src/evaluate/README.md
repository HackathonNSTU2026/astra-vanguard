# Evaluator - Оценщик качества

Используется для измерения качества вашего решения функцией `check()` на публичном наборе `dataset/dev.jsonl`.

## Файлы

| Файл | Назначение |
|------|------------|
| `evaluate.py` | Оценщик качества. Загружает JSONL, посылает запросы на ваш API (`POST /v1/check`) или берёт готовые предсказания, считает скор и метрики. Только стандартная библиотека Python 3.10+. |
| `test_evaluate.py` | Юнит-тесты `unittest` для функции `score` из `evaluate.py`. |
| `__init__.py` | Делает папку пакетом, экспортирует `score`. |

## Возвращаемые параметры

| Параметр | Описание | Целевое значение для нас |
|----------|----------|--------------------------|
| `score` / `cost_score` | Итоговый сбалансированный cost-скора (точность + задержка + штрафы + бонусы) | Чем выше, тем лучше; должен пройти заданный gate (порог прохождения) |
| `p95_latency_ms` | p95 задержка ответа API в миллисекундах | Чем меньше, тем лучше; цель ≤ 3000 мс (без штрафа за latency) |
| `precision` | Precision (доля правильных срабатываний среди всех срабатываний) | Чем ближе к 1.0, тем лучше |
| `recall` | Recall (доля правильно найденных опасных случаев среди всех опасных) | Чем ближе к 1.0, тем лучше; критично не пропускать опасные примеры |
| `f1` | F1-мера (гармоническое среднее precision и recall) | Чем ближе к 1.0, тем лучше |
| `macro_f1` | Макро-F1 (усреднённый F1 по классам) | Чем ближе к 1.0, тем лучше |
| `confusion_matrix` | Матрица ошибок [[TP, FN], [FP, TN]] | Минимизировать FN (особенно на опасных примерах) и FP |
| `latency_penalty` | Штраф за задержку (>3000 мс и >6000 мс) | 0 (задержка не должна превышать 3000 мс) |
| `critical_block_rate` | Доля решений `block` на высококритичных примерах | ≥ 85% (gate на высококритичных примерах) |
| `cpu_bonus` | Бонус за эффективность использования CPU | Чем выше, тем лучше |
